# krzky.github.io

Published snapshot of **https://krzky.github.io**, served by GitHub Pages from
`main` (root folder, `.nojekyll`).

This repository only holds the files the browser requests. The source, design
notes and full history live in a private repository, and this branch is
rewritten as a single commit by `scripts/deploy-pages.sh` on every deploy — so
edits made here by hand will be replaced on the next publish.
