Undergraduate thesis · 2026

An outlet that thinks before it cuts.

Final project in Electrical Engineering at President University — a single-phase smart outlet that measures, protects, and keeps its record when the network goes down.

Electricity Safety and Usage Monitoring Using Arduino Nano Every with a Web-Based Power Outlet System

A traditional outlet protects nothing and reports nothing. This prototype adds a PZEM-004T energy sensor, MCCB and relay cutoff, and a W5500 Ethernet link to a web dashboard — so an ordinary wall socket can warn, disconnect, and account for every watt.

The hard part was not the dashboard; it was keeping the record intact. When connectivity drops, readings are written to a 32 KB AT24C256 EEPROM and replayed to the server once the link returns. The same controller drives an OLED readout, RGB status light, and an audible alarm, so the state of the circuit stays legible with or without a browser.

  • Arduino C++
  • ATmega4809
  • PZEM-004T
  • W5500
  • Web dashboard
